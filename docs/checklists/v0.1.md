# v0.1 Phone Test Checklist

Run on the iPhone 11 via Expo Go, with the backend running on the Mac and both on the same Wi-Fi.
v0.1 is not done until every box is checked **and** GitHub Actions is green.

## Setup and first run
- [ ] First launch shows the onboarding survey; all fields validate (no empty or impossible values)
- [ ] Switching between metric and imperial converts the displayed values correctly
- [ ] Finishing the survey lands on Home with a sensible calorie target
- [ ] Gain/lose/maintain each change the target in the expected direction; an extreme rate is capped or refused
- [ ] Closing and reopening the app skips onboarding and keeps my data

## Look and navigation
- [ ] The app is dark (near-black background, purple cards, orange accents) and the text is easy to read
- [ ] Four tabs along the bottom: Home, Food, Workout, Profile; the active one is orange
- [ ] Calendar button (top right) on Home, Food and Workout opens the calendar over a faded screen; the tabs stay usable and tapping one closes it
- [ ] Tapping a day in the calendar shows its summary; More shows foods, macros and nutrients; Less folds them away
- [ ] Days with a workout show an orange dot
- [ ] After picking a past day, Food and Workout say "Adding to <that day>" and add to it

## Food
- [ ] Searching a common food (e.g. "banana") returns results
- [ ] Searching a branded food returns results, or I can add it manually
- [ ] Choosing an amount on the wheels (e.g. "1/2 small bowl", "1 container") works and calories update as I scroll
- [ ] Logging 100 g of a food adds the right calories to Home, and "calories left" goes down by the same amount
- [ ] Logging by serving (e.g. "1 bar") gives the same result as the equivalent grams
- [ ] A food I added by hand is found first next time
- [ ] Edit changes an entry's amount; Remove deletes it; Home updates
- [ ] Swiping left on Food shows Nutrition; tapping a food shows its share in orange; swiping right (or tapping the dots) comes back

## Workout
- [ ] "This week" chart shows Sunday on the left to Saturday on the right, with mm/dd under each weekday
- [ ] Adding a workout (activity, minutes, intensity) shows it below, adds a bar for that day, and Home shows Burned and the balance
- [ ] Typing calories ("if known") overrides the estimate; leaving it empty estimates
- [ ] Remove deletes the workout and the chart updates
- [ ] Each wheel has its own border; the intensity descriptions fit on two lines

## Profile
- [ ] Goal, pace, resting burn and protein/fat/carbs match what the survey gave
- [ ] Details explains how the numbers were set; Hide details folds it
- [ ] Edit / Edit my answers open the survey filled in; Cancel returns to Profile
- [ ] Check connection opens the connection check

## Robustness
- [ ] Airplane mode shows a clear error, not a crash
- [ ] Changing the phone's timezone or date near midnight doesn't misplace entries
- [ ] Nothing crashes during a 10-minute normal-use session
